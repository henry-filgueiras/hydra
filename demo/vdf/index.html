A verifiable delay function, computed and verified in your browser

A VDF proves that real wall-clock time has passed: computing y = x2T mod N takes T squarings in a row — each one needs the last, so no amount of parallel hardware shortcuts it. The trick (Wesolowski, 2018) is that checking the result doesn't take T steps: a short proof π lets anyone verify in milliseconds. Watch the slow part be slow, then the verify be instant — all of it Hydra running as WebAssembly via hydra-bignum.

Honesty notes. This page is its own trusted setup: it generates N = p·q locally and drops p and q, but whoever knows φ(N) can reduce the exponent and skip the delay — real deployments use an RSA challenge number or class groups. The prover here is deliberately naive (it re-exponentiates from scratch, ≈2× the evaluation work; production provers checkpoint). The challenge prime is 256-bit hash-then-next-prime Fiat–Shamir. Hydra is variable-time by design — exactly right for a VDF, where every input is public, and exactly wrong for secret keys.
